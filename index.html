VS Code Extension v1.0.0

Intelligent Database Control Suite for VS Code

Zero-noise Pydantic DB scanner, automatic model-to-engine attribution (PostgreSQL, SQLite, Redis, TinyDB, Mongo), interactive ERD diagrams, and Forensic audit inspection.

Explore Features Installation Guide

Zero-Noise Pydantic Filter

Automatically separates database-bound models from plain FastAPI schemas or settings, hiding un-bound Pydantics to eliminate visual clutter.

Multi-Engine Attribution

Categorizes every model by its exact database target (wpostgresql, wsqlite, wredis, wtinydb, wmongo, etc.) with badges for multi-DB backups.

Forensic Audit Inspector

Highlights ForensicModel classes with status=99 soft delete indicators and UTC audit timestamps (create_by, update_in, delete_by).

Interactive ERD Visualizer

Generates dynamic SVG/Mermaid Entity-Relationship Diagrams directly from workspace models in one click.

CodeLens & Hover Tooltips

Inline CodeLens action buttons above database models and rich hover cards displaying SQL types, primary keys, and constraints.

Model & Connection Wizards

Interactive step-by-step QuickPick wizards to generate Pydantic DB models and safe connection configurations with env variables.

Quick Installation

bash 
# Clone and build wdatabase-vscode
git clone https://github.com/wisrovi/wdatabase-vscode.git
cd wdatabase-vscode
npm install && npm run compile

# Install extension into VS Code
code --install-extension wdatabase-vscode-1.0.0.vsix
